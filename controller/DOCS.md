# 使用方式

啟動 Runner 與 Controller。用 HA owner 點「開啟 Web UI」→「連線與設定」→貼上 Runner 記錄中的配對 JSON。

完成官方登入後，到「設備與權限」選擇可讀設備與專用 helpers／低風險燈具。工作台送需求、預覽規則、批准執行。等待真實來源觸發後會顯示證據；也可使用兩個專用 test helpers 的測試按鈕。

停用現有規則在「家庭自動化」；暫停 AI 不會停用原生 HA 規則。錯誤時使用 HA 原生介面管理設備與備份。

資料在 App 私有 `/data`，請用原生 App backup 或工作台加密匯出保留。不要用同一時間的原生 editor 修改正在部署的同一條規則。
