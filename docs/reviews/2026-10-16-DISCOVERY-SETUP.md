# 接入進度與讀回（2026-10-16）

使用者離開探索清單到 HA 原生設定後，原本沒有保存正在接入哪個候選，也無法區分候選消失與接入成功。本增量提供共用接入追蹤：保存精簡候選，回來由 Owner 選定整合實例，重新讀取關聯設備與 API 狀態。正式產品與公開示範沿用同一介面。

## 範圍與設計

- 唯讀 HA adapter 保持原範圍，設定與帳號授權在固定 HA 原生入口完成。沒有新模型工具、家庭 policy 或 HA 設定／設備寫入。
- Controller 的私有 `discovery_setup` v1 保存候選、同類整合起始清單及選擇；不保存整屋快照。SQL schema 保持 3，舊 binary 忽略但不清理此 kind，詳見 [資料相容性](../RELEASE_POLICY.md#接入追蹤資料相容性d3b)。
- 持久 scope 綁定 Owner 與 HA token／來源；短期登入世代另做請求檢查。建立、選擇與忘記採原子去重收據，選擇／忘記採 revision 檢查，回應落盤後重驗即時 Owner 與 Host／bridge authority。
- API 列表至多 20 筆；選項與設備各至多 100 筆。來源不完整保留未知；可用狀態是關聯設備的 HA entity 觀測，不是全部整合功能或物理動作證明。
- UI 延後讀取、無預選整合、錯誤不重標舊資料、晚到回應隔離；外層與側欄使用同一元件。公開示範資料只存在瀏覽器記憶體，重載會重設。

本機後端 **264 passed**（setup 28、discovery 50、bridge 137、durability 49），包含磁碟重開、跨登入續接、不同家庭隔離、去重與到期收據、競態／撤權與內外層回應落盤後的 Owner 檢查。HA 回應為合成協定資料，沒有對家庭設備進行寫入。

正式編譯接入介面 **28 passed**；既有探索、分享與側欄介面回歸 **41 passed**。涵蓋同名整合、無預選、候選消失、部分來源、清單截斷與完整總數、同鍵重試、revision 衝突、錯置讀回、身份切換及晚到回應。390／768／1440 px 的外層與側欄共 30 張 before／after 後的狀態畫面已保存私有收據並檢視；正式 Controller／Bridge 資源已同步重建。公開 10 張截圖另由本輪已提交來源生成，manifest 保存 commit、frontend tree 與逐檔雜湊。

公開示範的兩項新接入流程在手機／桌面通過：原生設定返回、精確選擇、跨產品介面共用追蹤、忘記後 HA 整合仍存在，且 policy／對話／任務不變。早期測試失敗是測試導航未等待桌面外框或未展開手機選單；修正後兩項重新通過。早期 UI 響應式測試的同 hash 導航未重新載入，也已修正並完整重跑 28 項。一次 Chromium 截圖協定失敗保留在私有紀錄，未改產品後完整重拍 10 張成功。

TypeScript（產品與示範）、Ruff、29 份 contracts、鎖定 web toolchain、App 套件／資源／文件連結檢查通過。完整 CI 與發布產物以本 PR 最終來源檢查及下載收據為準；合併前要求 push 與 pull_request 兩份完整套件成功，不以局部測試替代。

測試一律經磁碟暫存 wrapper，測試服務隨測試清理。真品牌帳號、實體家庭、多來源掃描與既有 ISO 更新不在本輪證據範圍；32 案維持 2 passed、30 not_run。
