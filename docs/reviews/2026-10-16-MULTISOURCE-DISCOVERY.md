# 多來源設備盤點與接入（2026-10-16）

原有探索只讀 HA 已知資料，沒有從主機網路或路由器清單取得新線索。本增量接通實際 Host 鄰居表／mDNS／SSDP 收集、通用路由器清單匯入、附證據的整合建議、保存與接入追蹤、選取後分享給管家，以及公開 HA 介面示範。流程不限定單一家庭品牌。

## 實作與範圍

- Host 固定 Unix 路徑，只接受主機產生且當下仍有效的實體 IPv4 網路範圍。八種固定 mDNS 類型與一次 SSDP 查詢；總期限六秒、接收視窗 2.5 秒、15 秒冷卻、單一掃描鎖。封包、位元組、命令輸出與每來源筆數都有上限。沒有任意 shell／CIDR、port sweep、TXT 或 LOCATION 下載。
- JSON／CSV／dnsmasq 匯入最多 64 KiB、256 列，只保存欄位白名單。每來源各自命名，不以名稱、MAC 或 IP 猜測合併。服務宣告、品牌提示、來源新鮮度與未知設備分開呈現。
- Controller 保存最新 LAN 與一份匯入清單，24 小時後停止當前接入建議；現有 context 保存政策按來源時間清理。清除保留不含設備內容的 revision tombstone。SQL schema 仍為 3，舊 binary 的忽略與清理限制見 [相容性](../RELEASE_POLICY.md#網路盤點資料相容性)。
- Owner／家庭來源 HMAC 隔離，請求前後與落盤後核對身份。修改具原子去重收據，clear 具 revision 檢查；並行掃描／匯入序列化。公開快照最多 750 KiB，超量投影明示部分／截短，避免側欄傳輸過大。
- 網路建議可建立既有接入追蹤，HA 整合仍由原生 UI 設定。回來明確選擇實例，讀回登錄設備與 API 狀態；沒有自動認定實體身份、設定成功或授予控制。
- 外層與側欄重用同一產品元件。分享只含所選觀測與來源，位址、MAC、原始匯入內容、未選資料不默默送入草稿。失去身份時清除在途畫面與原文；重新連線先讀保存結果。相同鍵重試限於目前身份與視圖仍保留的未確認操作。
- 公開示範使用記憶體家庭，包含不同品牌服務與未辨識端點、路由器匯入、原生設定交接與接入讀回；不接觸訪客網路。
